# MiniPong 🏓

MiniPong é um jogo de ping_pomg desenvolvido em Unity 6 com C#. Criei o projeto para praticar desenvolvimento de jogos e programação.

## Sobre o jogo

Dois jogadores controlam as raquetes e tentam rebater a bola. Quando a bola passa pela raquete adversária, o jogador marca um ponto, que aparece no placar.

## Controles

- Jogador 1: [W e S]
- Jogador 2: [O e L]

## Tecnologias

- Unity 6
- C#
- Visual Studio

## Como abrir o projeto

1. Baixe ou clone este repositório.
2. No Unity Hub, selecione **Add project from disk** e escolha a pasta do projeto.
3. Abra o projeto no Unity 6.
4. Abra a cena `Assets/Scenes/SampleScene.unity` e pressione **Play**.
